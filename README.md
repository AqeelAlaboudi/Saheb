# 🏠 Saheb | صاحب
Roommate matching prototype for Jubail Industrial College students.

🌐 [Live Demo](https://aqeelalaboudi.github.io/Saheb/).

---

## 🚀 Overview
An interactive single-file web application designed to solve common living conflicts and match compatible roommates based on lifestyle habits (such as sleep schedules, cleanliness, budgeting, and guest preferences).
